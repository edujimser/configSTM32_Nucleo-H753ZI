RELOJES DE HORA

Reloj analogico

data-clock

Usa la zona horaria de la variable rtc_tz (o data-tz="minutos" / data-tz="otra_variable").

Como se usa
<canvas data-clock="rtc" data-mode="analog" style="width:220px;height:220px"></canvas>
// web_vars.c   (ID, paginas, tipo, decimales, variable)
WVW("rtc", PG_WDATOS, WV_U32, 0, rtc_epoch, 0, 4294967295.0),   // segundos UNIX UTC
WVW("rtc_tz", PG_WDATOS, WV_I32, 0, rtc_tz, -720, 840),           // minutos de zona

Trama (bytes)

Lectura:

Editable (pagina CAN):

Ver las paginas CAN y TRDP.

// dos variables uint32 (lo = bytes 0-3, hi = bytes 4-7) y la longitud. Ver web_bus.c.

CONDICIONES, HISTORIAL Y EXPLICACIONES

Condiciones en vivo

data-cond
  • Interior mayor que exterior
  • CPU por debajo del 80 %
  • Heap por debajo del 85 %
Como se usa
<ul data-condlist>
  <li data-cond="s_cpu<80">CPU por debajo del 80 %</li>
  <li data-cond="t_int>sp_t+1">Interior mayor que consigna + 1</li>
</ul>
<!-- operadores: > < >= <= == != & (algun bit) !& (ningun bit); sumas y restas con numero o variable -->
