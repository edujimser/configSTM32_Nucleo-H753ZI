TUYO: widgets propios

Widget con tu codigo JS

VARS.widget
- (temp x 2)

Con esto puedes dibujar lo que quieras: SVG, canvas, three.js...

Como se usa
<span data-doble="temp"></span>

<script>
  VARS.widget("data-doble", function (el, d, todos) {
    var v = d[el.getAttribute("data-doble")];   // d = valores que acaban de llegar
    if (typeof v === "number") el.textContent = (v * 2).toFixed(1);
  });
  // window.onVars = function (d) { ... }  recibe cada mensaje completo
</script>

Pasos para cualquier widget

1. En web_vars.c registra la variable con una linea (WV si solo se lee, WVW si la web puede cambiarla).
2. En tu HTML pon el atributo data-xxx="ID" en un elemento.
3. Compila la placa. Si has cambiado un HTML, regenera packed_fs.c con el empaquetador.
