Heap = memoria dinamica de FreeRTOS (hilos, colas, mutex). RAM estatica = .data + .bss, aproximada.

Como se usa
<div class="barra" data-bar="s_hpct" data-min="0" data-max="100"><i></i></div>
// web_sys.c: xPortGetFreeHeapSize(), xPortGetMinimumEverFreeHeapSize()
// "Minimo libre" es lo mas bajo que ha llegado el heap desde el arranque: si se acerca a 0, hay riesgo.

Stack libre = el minimo que ha quedado libre desde que arranco el hilo (high water mark). Menos de 256 B sale en rojo.

Como se usa
<tr data-show-if="t1_n">                                  <!-- la fila solo se ve si el hilo existe -->
  <td data-v="t1_n"></td>                                   <!-- nombre (texto) -->
  <td><span class="est" data-v="t1_s"
        data-map="0:EJECUTANDO,1:LISTO,2:BLOQUEADO,3:SUSPENDIDO,4:ELIMINADO"></span></td>
  <td data-v="t1_p"></td>                                   <!-- prioridad -->
  <td><span class="barra mini" data-bar="t1_c"><i></i></span><span data-v="t1_c"></span>%</td>
  <td data-v="t1_f" data-alarm="t1_f" data-lo="256"></td>   <!-- rojo si queda menos de 256 bytes de stack -->
</tr>
// web_sys.c: sys_th_n[i] (WV_STR), sys_th_s[i], sys_th_p[i], sys_th_c[i], sys_th_f[i]
// el hilo con CPU alta o poco stack libre es el que hay que revisar
