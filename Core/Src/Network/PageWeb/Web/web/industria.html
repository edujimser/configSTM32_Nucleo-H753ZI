TABLAS

Tabla configurable: valor, led, barra o alarma

data-tabledata-typeslee
Como se usa
<table class="tabla"
  data-table="m1_rpm,m1_t,m1_a,m1_run,m2_run"
  data-names="Velocidad M1,Temperatura M1,Corriente M1,Motor 1,Motor 2"
  data-units="rpm,C,A,,"
  data-types="barra,alarma,valor,led,led"     <!-- como se muestra cada fila -->
  data-limits="0:3000,:70,,,"                 <!-- barra: min:max | alarma: bajo:alto -->
  data-texts="1:MARCHA,0:PARADO"></table>      <!-- texto de los leds -->

<!-- tipos: valor (por defecto) | led (verde si distinto de 0) | barra | alarma (rojo fuera de limites) -->
// cada fila es una variable de web_vars.c con PG_INDUSTRIA (o la pagina donde pongas la tabla)

Registro de alarmas

data-alarmloglee

Anota hora, variable y evento cada vez que una variable entra o sale de limites. El registro lo guarda el navegador mientras la pagina esta abierta.

Como se usa
<table class="tabla log" id="talarmas"
  data-alarmlog="m1_t::70:Temp M1,presion:2:8:Presion" data-max="8"></table>
<!-- formato: id:bajo:alto:nombre   (vacio = sin limite) -->
// no necesita nada especial en C: se usan las variables normales

Marcha, paro y emergencia

data-cmddata-confirmescribe

Respuesta:  

Para seguridad real, el paro de emergencia debe ser cableado: la web es un mando adicional, no una proteccion.

Como se usa
<button class="btn" data-cmd="start">MARCHA</button>
<button class="btn rojo" data-cmd="emergencia" data-confirm="CONFIRMAR?">EMERGENCIA</button>
<!-- data-confirm: la primera pulsacion arma el boton 3 s, la segunda envia el comando -->
// web_vars.c, seccion 4: comandos. Cortos: ponen un flag o cambian una variable
static void cmd_start(const char *arg) { orden_marcha = 1; }
static const WebCmd_t web_cmds[] = { {"start", cmd_start}, ... };
