// Todo se libera solo a los 600 s (WEBBUS_FORCE_TIMEOUT_S).

Señales

data-signalsdata-setescribe

Marca FORZAR en una señal y escribe su valor fisico. Solo actua si FORZAR SEÑALES esta activo. RX forzada: tu variable recibe ese valor aunque el bus diga otro. TX forzada: se transmite ese valor en vez de tu variable.

Para añadir o quitar señales edita web_sig_cfg.h: no hay que tocar HTML ni la tabla de variables.

Como se usa
<table class="tabla bus" data-signals="g" data-bus="0"></table>
<!-- la tabla se rellena sola con el catalogo de web_sig_cfg.h (GET /api/senales?bus=0) -->
<!-- por cada señal j:  <input type="checkbox" data-set="gf0">  (FORZAR)    <input type="number" data-set="gx0">  (valor forzado) -->
// web_sig_cfg.h  (un solo archivo para añadir señales; ver su cabecera)
//   RX:  X( CAN_T_INT, 0x100u, 0, 16, 0, 0.1f, 0.0f, "C", "Temperatura interior", mi_temp = v)
//   TX:  X( CAN_SP,    0x200u, 0, 16, 0, 0.1f, 0.0f, "C", "Consigna", consigna)
//   TRAMA TX: X( 0x200u, 8, 500 )   // id, dlc, periodo ms
// valor fisico = raw * factor + offset; numeracion de bits Intel (bit 0 = LSB del byte 0).

AYUDA

Como funciona

ayuda
Señales, tramas RX y tramas TX

Señales: cada valor de una trama (como en un DBC) se muestra en unidades fisicas y se puede forzar uno a uno. Tramas RX: con el forzado activo, tu aplicacion ve los bytes que pones. Tramas TX: la web envia las tramas de su tabla.

Seguridad

Forzar datos en un bus de un tren puede mover equipos reales. Usalo solo en banco o con el tren parado. Todo se desactiva solo a los 10 minutos y la web no tiene contrasena.

Como añado una señal

Edita web_sig_cfg.h: una linea por señal con trama, bit de inicio, longitud, factor, offset, unidad, descripcion y tu variable. No hay que tocar nada mas.

Orden de bytes

Las señales usan numeracion Intel (bit 0 = LSB del byte 0). La vista de tramas muestra el byte 0 primero. Longitud real: DLC.
