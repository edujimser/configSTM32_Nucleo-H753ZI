REGULACION PID

Faceplate PID

data-pidescribelee

Tu regulador PID (en C) lee pid_modo / pid_manual / ganancias y escribe pid_salida: la web solo es el panel de operador.

Como se usa
<div data-pid data-pv="t_int" data-sp="sp_t" data-out="pid_out" data-mode="pid_mode"
     data-man="pid_man" data-kp="pid_kp" data-ki="pid_ki" data-kd="pid_kd"
     data-unit="C" data-sp-min="10" data-sp-max="30"></div>
<!-- un solo elemento: la pagina construye PV, SP, salida, AUTO/MANUAL, ganancias y grafica -->
// web_vars.c: PV y salida de lectura; consigna, modo, salida manual y ganancias ESCRIBIBLES
WV ("t_int",    PG_HVAC, WV_FLOAT, 1, temp_interior),
WV ("pid_out",  PG_HVAC, WV_FLOAT, 1, pid_salida),
WVW("pid_mode", PG_HVAC, WV_U8,    0, pid_modo,   0, 1),     // 0 AUTO, 1 MANUAL
WVW("pid_man",  PG_HVAC, WV_FLOAT, 1, pid_manual, 0, 100),
WVW("pid_kp",   PG_HVAC, WV_FLOAT, 2, pid_kp,     0, 50),    // y pid_ki, pid_kd, sp_t

CIRCUITO FRIGORIFICO 1

Esquema del circuito (frio / calor)

data-statedata-vlee

Tuberias rojas = lado caliente (descarga/condensacion), azules = lado frio. Se invierten con la valvula de 4 vias.

Como se usa
<svg class="circuito" data-state="c1_4v">           <!-- c1_4v: 0 frio, 1 calor (valvula de 4 vias) -->
  <path class="tubo p-ext" d="M320,80 H140"/>       <!-- el color y el sentido cambian solos -->
  <g data-state="c1_st"> ...flujo, compresor... </g> <!-- el flujo se mueve si el compresor marcha -->
  <text>HP <tspan data-v="c1_hp"></tspan> bar</text> <!-- cualquier dato vivo dentro del dibujo -->
</svg>
// 4 vias: WV ("c1_4v", PG_HVAC, WV_BOOL, 0, valvula4v_calor), compresor: WV ("c1_st", PG_HVAC, WV_U8, ...)  0 parado 1 arrancando 2 marcha 3 fallo

Presostatos y seguridades

data-bitslee

Verde = contacto cerrado (OK). Rojo = disparado.

Como se usa
<div class="bits inv" data-bits="in_w" data-count="8" data-names="AP1,BP1,AP2,BP2,TER C1,TER C2,TER EV,TER CD"></div>
<!-- class="inv": el led se pone ROJO cuando el bit es 0 (un presostato cerrado = 1 = OK) -->
// un byte con una entrada digital por bit: bit0 = presostato AP1 (1 = cerrado/OK)
in_w = (ap1 << 0) | (bp1 << 1) | (ap2 << 2) | (bp2 << 3);
WV ("in_w", PG_HVAC, WV_U8, 0, in_w),
