Trampillas

AUTO = decide el regulador. OFF / ON = fuerza el componente. El led muestra la salida real.

Pon el sistema en AUTO al terminar. En un tren real, restringe quien puede usar el mando manual.

Como se usa
<button class="btn fino" data-set="m_c1" data-value="0">AUTO</button>
<button class="btn fino" data-set="m_c1" data-value="1">OFF</button>
<button class="btn fino" data-set="m_c1" data-value="2">ON</button>
<span class="led" data-bit="out_w:0"></span>   <!-- bit 0 de la palabra de salidas -->
// web_vars.c: variable ESCRIBIBLE (WVW) con limites minimo y maximo
WVW("m_c1", PG_WIDGETS, WV_U8, 0, mando_comp1, 0, 2),
WV ("out_w", PG_COMPON, WV_U16, 0, salidas_digitales),   // un bit por salida real

// en tu control:  run1 = (mando_comp1 == 1) ? 0 : (mando_comp1 == 2) ? 1 : run1_auto;
